# Task-1-Data-Cleaning-and-Preprocessing-new
This project checks and displays the unique values in text columns of a dataset to help standardize and clean the data.
For Task 1, I selected the Job Descriptions dataset from Kaggle. Since the task description did not specify a particular dataset, I chose one that contains several data quality issues requiring preprocessing and cleaning. This dataset provided a suitable opportunity to demonstrate the required data cleaning techniques and effectively meet the objectives of the task.
